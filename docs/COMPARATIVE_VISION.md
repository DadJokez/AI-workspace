# Comparative
## The Operating System for Knowledge Work

### Vision

Most enterprise AI products start with chat.

Comparative starts with work.

Employees do not wake up wanting a better chatbot.

They want to:

- find information faster
- automate repetitive work
- reuse expertise
- build tools without waiting months
- share what works with their teams

Comparative is designed to become the operating system for knowledge work.

A single environment where employees can:

- chat with AI
- access enterprise systems
- create reusable Skills
- automate those Skills
- build lightweight applications
- share capabilities with teammates
- discover new ways of working

without needing to understand models, APIs, integrations, or infrastructure.

The platform abstracts technology so users can focus on outcomes.

---

# The Core Insight

Most organizations already have:

- data
- applications
- workflows
- employees
- AI models

What they lack is a layer that connects them.

Today employees are the integration layer.

They move information between systems, repeat tasks, recreate workflows, and carry institutional knowledge in their heads.

Comparative is designed to become that missing layer.

---

# The Five Building Blocks

## 1. Chat

Conversation is the universal interface.

Users start by asking questions and requesting work.

## 2. Skills

A Skill is reusable expertise.

Skills transform one person's workflow into an organizational asset.

## 3. Scheduled Agents

Useful Skills should not require manual execution.

Scheduled Agents run automatically.

This is where AI becomes proactive rather than reactive.

## 4. Apps

Some workflows eventually need a dedicated interface.

The progression becomes:

Question → Skill → App

without requiring traditional software development cycles.

## 5. Sharing

Knowledge compounds when it spreads.

Skills, Apps, and future Agents can be shared across teams.

---

# Agent Wire

Comparative is designed to learn how the organization works.

Agent Wire captures usage patterns and capability adoption so organizations can understand:

- what creates value
- what spreads
- what should be standardized
- where AI is actually helping

---

# Long-Term Vision

The long-term goal is not to build another AI assistant.

The goal is to create an operating system for knowledge work.

A place where:

- people work
- AI works
- expertise becomes reusable
- automation becomes discoverable
- applications emerge from conversation
- organizational knowledge compounds over time

Comparative succeeds when useful work becomes reusable work.
