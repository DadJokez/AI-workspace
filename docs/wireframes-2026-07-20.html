Grayscale layout sketches for the recommendations in design-audit-2026-07-20.md. These show structure and behavior, not final visuals — in production everything picks up the Umber palette (warm neutrals, parchment tan, one forest-green highlight per screen). Numbered dots are annotations; read them with the list under each drawing.

1.Main layout — sidebar, chat, slide-over panel

The overall shell keeps today's three-column idea, with two changes: the thread list gets pinning and date groups, and panels like Tools/Vault slide in on the right instead of replacing your chat.

  • 1

    Collapsible sidebar. Same 240px column as today, but a toggle shrinks it to a thin icon rail — useful on laptops, and automatic on tablets when a right panel is open.

  • 2

    Search lives in the sidebar and opens the ⌘K palette (figure 4). This replaces the current SearchPanel, which nothing in the UI can actually open today.

  • 3

    Thread list gets Pinned / Today / Previous 7 days groups. Right now it's one flat list — hard to find anything once you have 30+ chats. Pin lives in each row's ⋯ menu.

  • 4

    Settings moves to the account area and opens as a modal over the chat (figure 3), so you never lose your place in the conversation.

  • 5

    The model is always visible in the header — even in runtime-V2 mode, where today the picker just disappears. Honesty about "which model answered" is part of the product's spine.

  • 6

    Tools / Vault / Artifacts slide in from the right as a resizable panel (drag the grip) instead of replacing the whole chat. The chat and its scroll position stay put. This reuses the split-pane code that artifacts already have.

2.Message thread — user vs AI, tool work, citations

The current asymmetry is kept (user = compact bubble, AI = full-width text) because it reads well. Additions: timestamps, a clearer work receipt, and a new sources row for when answers rely on tools or documents.

3.Settings — modal with a section rail

Today Settings replaces the entire chat and is one long scroll. Proposed: a centered modal (chat stays visible behind it) with sections on the left — the pattern Claude.ai, Linear, and Notion all use. Memory (Vault) and Integrations (Tools) become sections here too, so everything about "how my assistant behaves" lives in one place.
