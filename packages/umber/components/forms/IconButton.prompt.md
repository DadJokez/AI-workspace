**IconButton** — a square, icon-only action for toolbars, table rows, and dense chrome. Always pass `aria-label`.

```jsx
<IconButton aria-label="More options"><Icon name="ellipsis" /></IconButton>
<IconButton variant="outline" aria-label="Copy"><Icon name="copy" /></IconButton>
```

Variants: `ghost` (default), `outline`, `solid`. Sizes `sm | md | lg`.
