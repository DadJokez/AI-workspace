**Tabs** — horizontal underline tab bar for switching views within a page. Controlled or uncontrolled.

```jsx
<Tabs defaultValue="overview" onChange={setTab} items={[
  { value: "overview", label: "Overview" },
  { value: "queries", label: "Queries", badge: 12 },
  { value: "settings", label: "Settings" },
]} />
```
